# RegistroDoc

Sistema de Gestão Eletrônica de Documentos para serventias de
Registro Civil das Pessoas Naturais (RCPN).

## Objetivo

Catalogar, indexar e pesquisar documentos digitalizados,
preservando os arquivos originais e controlando o acesso
às informações.

## Escopo inicial

Habilitações de casamento digitalizadas em PDF pesquisável.

## Tecnologias

- .NET 10
- ASP.NET Core Web API
- Blazor
- PostgreSQL (previsto)
- Worker Service
- xUnit
- Docker
- GitHub Actions (previsto)

## Arquitetura

- RegistroDoc.Api
- RegistroDoc.Web
- RegistroDoc.Domain
- RegistroDoc.Application
- RegistroDoc.Infrastructure
- RegistroDoc.Contracts
- RegistroDoc.Indexer

## Segurança

O repositório contém somente código-fonte e dados fictícios.

Documentos reais, informações pessoais, credenciais,
backups e dados internos de serventias não devem ser publicados.

## Estado do desenvolvimento

Fundação .NET 10 criada e compilada.

A integração com o banco de dados e a indexação
documental ainda não foram implementadas.
