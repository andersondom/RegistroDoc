# Como continuar no Codex (VS Code)

1. Abrir a pasta RegistroDoc no VS Code.
2. Atualizar o repositório com segurança (verificar git status antes de pull; preservar alterações locais).
3. Garantir que a documentação desta branch esteja disponível na branch de trabalho.
4. Abrir o painel Codex e enviar:

> Leia AGENTS.md, docs/REQUISITOS.md, docs/HOMOLOGACAO.md e docs/PROGRESSO.md. Inspecione o código real e continue a partir das pendências. Comece pelas falhas de paginação, nova pesquisa após paginação e abertura de PDF. Crie branch de correção, não altere main diretamente, preserve dados e segurança, implemente testes, execute os testes disponíveis e atualize docs/PROGRESSO.md. Peça autorização para ações destrutivas ou merge.

5. Conferir o diff e os resultados. Testar com documentos fictícios.
6. Após cada sessão: pedir ao Codex para atualizar PROGRESSO.md com o que foi efetivamente concluído.

Nota: esta documentação não importa o histórico completo do ChatGPT nem substitui a inspeção do código atual. Ela reúne os fatos e decisões relevantes para a retomada.
